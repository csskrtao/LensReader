# LensReader

上传英语文章照片 → AI 识别成可交互文本 → 点词 / 点句 / 划线讲解、逐句翻译、生词本、历史记录。

## 运行

```bash
npm install
cp .env.example .env   # 已经有 .env 的话跳过
npm run dev            # 打开 http://localhost:5173
```

## 配置 `.env`

| 变量 | 说明 |
|---|---|
| `OPENAI_BASE_URL` | OpenAI 兼容接口地址，OpenAI 官方留空 |
| `OPENAI_API_KEY` | API Key |
| `VISION_MODEL` | 识图模型，**必须支持图片输入**（如 `gpt-4o`、`qwen-vl-max`） |
| `TEXT_MODEL` | 讲解/翻译模型 |

修改 `.env` 后需重启 `npm run dev`。

## 使用

- **多张照片合成一篇**：一次选多张（或多次添加 / 拖入 / Ctrl+V 粘贴），在待识别列表里按页码顺序排好（拖动或 ‹ › 调整，默认按文件名排序），点「识别并合成一篇」。各页并行识别后按顺序拼接：跨页断开的句子（含行尾连字符断词）会接成一句，跨页的段落会接成一段，相邻照片重复拍到的句子会自动去重
- **手机扫码拍照**：点顶栏「📱 手机拍照」显示二维码，手机扫码打开拍照页，可连续拍多张 / 从相册多选，每张拍完先进入裁剪（拖动方框只框住文章正文，可旋转；也可「使用原图」，或取消勾选「拍完后裁剪」跳过），确认后自动出现在电脑的待识别列表里（按拍摄顺序编号）。手机和电脑需连同一 WiFi；若扫码后打不开，在卡片里切换网卡 IP，或在 Windows 防火墙中允许 Node.js 访问专用网络。收起卡片不影响接收，点「断开」才结束
- **裁剪**：待识别列表里每张图右上角的 ✂ 可裁剪 / 旋转，只保留文章区域；识别时也会自动忽略题目、选项、注释、页眉页脚、手写笔记、截图界面文字等非正文内容
- **点词**（快捷键 1）：点单词 → 本句中的意思、翻译、音标、其他释义、搭配、例句
- **点句**（快捷键 2）：点句子 → 整句翻译、结构/成分分析、语法点、重点表达
- **划线**（快捷键 3）：按住从一个词拖到另一个词，或先点起点再点终点（可跨句）→ 固定搭配结构、用法、拓展意思、近义表达；划线会保存，点橙色序号可重新查看或删除；Esc 取消
- **逐句翻译**：译文显示在每句下方
- **先出快速结果**：点词时先显示有道词典的音标和释义，点句 / 划线 / 逐句翻译时先显示有道机翻（标“词典”“机翻”，本地运行时有道失败会改用谷歌翻译），AI 讲解返回后自动替换；快速接口不可用时不影响 AI 讲解
- 讲解面板中可「加入生词本」；所有数据（文章、划线、讲解缓存、生词本）保存在浏览器 localStorage

## 生产模式

```bash
npm run build && npm start   # 后端同时托管前端，访问 http://localhost:8787
```

## 部署到 Cloudflare

整体部署成一个 Cloudflare Worker（前端 + AI 接口 + 手机拍照会话），线上地址：https://lensreader.skrtao.de

```bash
npx wrangler login                          # 首次：浏览器授权 Cloudflare 账号
npx wrangler secret put OPENAI_API_KEY      # 首次：设置密钥
npx wrangler secret put OPENAI_BASE_URL     # OpenAI 官方可跳过
npx wrangler secret put ACCESS_CODE         # 访问口令，强烈建议设置，否则任何人都能用你的 Key
npm run deploy                              # 构建并部署，之后每次更新只需这一步
```

线上版扫码拍照直接使用当前域名，手机不需要和电脑连同一 WiFi。架构、域名配置、日常维护、访问口令和本地模拟等详细说明见 [docs/deploy-cloudflare.md](docs/deploy-cloudflare.md)。
