# 拍照精读

上传英语文章照片 → AI 识别成可交互文本 → 点词 / 点句 / 划线讲解、逐句翻译、生词本、历史记录。

## 运行

```bash
npm install
cp .env.example .env   # 已经有 .env 的话跳过
npm run dev            # 打开 http://localhost:5173
```

## 配置 `.env`

| 变量 | 说明 |
|---|---|
| `OPENAI_BASE_URL` | OpenAI 兼容接口地址，OpenAI 官方留空 |
| `OPENAI_API_KEY` | API Key |
| `VISION_MODEL` | 识图模型，**必须支持图片输入**（如 `gpt-4o`、`qwen-vl-max`） |
| `TEXT_MODEL` | 讲解/翻译模型 |

修改 `.env` 后需重启 `npm run dev`。

## 使用

- **多张照片合成一篇**：一次选多张（或多次添加 / 拖入 / Ctrl+V 粘贴），在待识别列表里按页码顺序排好（拖动或 ‹ › 调整，默认按文件名排序），点「识别并合成一篇」。各页并行识别后按顺序拼接：跨页断开的句子（含行尾连字符断词）会接成一句，跨页的段落会接成一段，相邻照片重复拍到的句子会自动去重
- **点词**（快捷键 1）：点单词 → 本句中的意思、翻译、音标、其他释义、搭配、例句
- **点句**（快捷键 2）：点句子 → 整句翻译、结构/成分分析、语法点、重点表达
- **划线**（快捷键 3）：按住从一个词拖到另一个词，或先点起点再点终点（可跨句）→ 固定搭配结构、用法、拓展意思、近义表达；划线会保存，点橙色序号可重新查看或删除；Esc 取消
- **逐句翻译**：译文显示在每句下方
- 讲解面板中可「加入生词本」；所有数据（文章、划线、讲解缓存、生词本）保存在浏览器 localStorage

## 生产模式

```bash
npm run build && npm start   # 后端同时托管前端，访问 http://localhost:8787
```
